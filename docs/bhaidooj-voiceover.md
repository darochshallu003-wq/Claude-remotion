# Bhai Dooj explainer: voiceover script (Hinglish)

Regenerate the AI voice with `python3 scripts/vo_tts.py bhaidooj` (questions are asked by a second voice), or record one clip per scene as `public/bhaidooj/vo/<file>.mp3`; then run `python3 scripts/vo_timing.py bhaidooj` and re-render:
`npx remotion render BhaiDoojExplainer out/bhai-dooj-explainer.mp4`.

## 1. `hook.mp3`  (~6.97 s)

रुको, भाई दूज पर सिर्फ़ टीका लगवाकर भाग रहे हो? इस दिन की असली कहानी… यमराज से जुड़ी है!

## 3. `vardaan.mp3`  (~9.95 s)

## 4. `twist.mp3`  (~8.89 s)

Plot twist! इस कहानी का असली hero टीका नहीं, खाना है। दक्षिण में इस दिन को कहते हैं भगिनी हस्त भोजनम्, यानी बहन के हाथ का खाना।

## 7. `kaanta.mp3`  (~8.31 s)
