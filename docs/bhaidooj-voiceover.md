# Bhai Dooj explainer: voiceover script (Hinglish)

The current voice is a human recording, imported with `python3 scripts/vo_import.py bhaidooj <take> --starts 3.2,14.2,21.9,31.4,45.4` (the raw take stays out of git, in `recordings/`). To go back to the AI voice, run `python3 scripts/vo_tts.py bhaidooj` and `python3 scripts/vo_timing.py bhaidooj`. Render with `npx remotion render BhaiDoojExplainer out/bhai-dooj-explainer.mp4`.
