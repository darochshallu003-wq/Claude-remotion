# Dahi explainer: voiceover script (Hinglish)

Regenerate the AI voice with `python3 scripts/vo_tts.py dahi` (questions are asked by a second voice), or record one clip per scene as `public/dahi/vo/<file>.mp3`; then run `python3 scripts/vo_timing.py dahi` and re-render.
