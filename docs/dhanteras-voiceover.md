# Dhanteras explainer: voiceover script (Hinglish)

Regenerate the AI voice with `python3 scripts/vo_tts.py dhanteras`, or record one clip per scene as `public/dhanteras/vo/<file>.mp3`; then run `python3 scripts/vo_timing.py dhanteras` and re-render.
