# Tetanus explainer: voiceover script (Hinglish)

Regenerate the AI voice with `python3 scripts/vo_tts.py tetanus` (questions are asked by a second voice), or record one clip per scene as `public/tetanus/vo/<file>.mp3`; then run `python3 scripts/vo_timing.py tetanus` and re-render.
